你已有的数据，是最高密度的建模材料

访谈和表单采集的是“你愿意说、能说出来的自己”；文件和设备采集的是“你已经留下、但不一定记得的自己”。后者数据密度更高、更接近真实行为——这是心理数字孪生区别于问卷工具的地方。

两个孪生，两条保真度轴

心智孪生 功能层

来自语言、行为、自述与记忆。描述你的偏好、情绪模式、决策倾向和表达习惯。数据越真实，画像越贴近你。

当前路径保真度
脑孪生 机制层

来自脑电与生理信号。描述你的神经状态、注意力、认知负荷与状态转换。空间与时间分辨率决定它的上限。

当前路径保真度

两条轴不是一条线的两端。心智孪生再丰富，也读不出神经状态；脑电信号再干净，也建不出记忆和人格。它们需要各自的数据源，最终在心智-脑耦合层对齐。

可以进来的数据

数据来源进入哪一层状态
结构化档案（JSON / CSV） 心智孪生 · 基线画像 内测
日记 / 聊天记录 / 文本语料 心智孪生 · 语言与情绪模式 内测
心理测评量表结果 心智孪生 · 结构化自我描述 内测
可穿戴设备（心率 / 睡眠 / 活动） 心智孪生 · 生理状态维度 内测
EEG / 脑电设备 脑孪生 · 神经状态层 研究性内测

前四类用于功能层建模；脑电目前用于状态层信号（注意力、认知负荷、情绪效价粗分类），不用于内容级读取。内容级解码属于研究议程，不在当前产品承诺范围内。

数据进来之后

01
来源追溯每条数据记录来源与时间，可回溯到原始材料。
02
特征抽取语言、行为、生理信号被抽取为可建模的特征。
03
一致性校验与已有画像比对，冲突不自动合并，交由你确认。
04
画像更新新特征进入孪生，旧特征按时间与可信度加权。
05
持续演化设备接入是实时流，孪生随时间更新，不是一次快照。

这条链路和访谈路径共用同一份数据契约。不管数据从哪个入口进来，最终都落到同一套画像结构，带版本号，可被下游直接消费。

边界与承诺

知情同意：数据接入前明确告知用途与范围。
可撤回：你可以在任何时候撤回已接入的数据，画像随之回退。
来源可追溯：每条特征都能回溯到原始材料，不做黑箱生成。
神经数据隔离：脑电等神经数据仅在内测环境使用，不进入对外服务。
不做承诺之外的事：内容级读取、高保真脑模型属于研究议程，不作为产品功能对外承诺。
